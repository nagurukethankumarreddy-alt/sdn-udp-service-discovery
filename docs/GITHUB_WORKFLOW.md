# Git workflow for this team

## Suggested ownership

- Member 1: `app/`
- Member 2: `controller/` and `topology/`
- Member 3: `integration/`, `tests/`, and `docs/`
- Shared files: `README.md`, `START_HERE.md`, `SOURCE_CODE_REFERENCE.md`, `.gitignore`

## Rules

1. Pull latest changes before work.
2. Avoid editing another member's files without coordinating.
3. Test your own changes before committing.
4. Use descriptive commit messages.
5. Prefer feature branches and pull requests if your team has time.
6. Never commit `.venv*`, `__pycache__/`, credentials, or local logs.

The Ubuntu terminal commands for initializing and pushing this project are provided separately in the chat.
